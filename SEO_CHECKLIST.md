# Проверочный список для SEO оптимизации PCComponents Store

## 1. ТЕХНИЧЕСКАЯ ОПТИМИЗАЦИЯ

### Индексация и структура
- [ ] Создан файл robots.txt (разрешаем индексацию каталога)
- [ ] Создан динамический sitemap.xml со всеми товарами
- [ ] Настроены canonical теги для избежания дублей
- [ ] Настроены редиректы 301 для старых URL
- [ ] Нет 404 ошибок в Google Search Console

### Скорость загрузки (Core Web Vitals)
- [ ] LCP ≤ 2.5 сек (проверено PageSpeed Insights)
- [ ] CLS ≤ 0.25 (нет неожиданных сдвигов контента)
- [ ] INP ≤ 200 мс (быстрый отклик на действия пользователя)

### Мобильная оптимизация
- [ ] Адаптивный дизайн на всех разрешениях (320px+)
- [ ] Нет горизонтальной прокрутки
- [ ] Корректный viewport метатег
- [ ] Сенсорные элементы (кнопки ≥ 48px)
- [ ] Читаемые шрифты (минимум 16px)

### Микроразметка Schema.org
- [ ] Organization разметка (информация о компании)
- [ ] BreadcrumbList (навигационная цепь)
- [ ] Product разметка (для каждого товара)
- [ ] FAQ разметка (для часто задаваемых вопросов)
- [ ] LocalBusiness разметка (адрес, контакты)

### Безопасность
- [ ] HTTPS на всех страницах
- [ ] Content-Security-Policy заголовок
- [ ] X-Frame-Options = SAMEORIGIN
- [ ] X-Content-Type-Options = nosniff

## 2. ОПТИМИЗАЦИЯ КОНТЕНТА

### Meta теги
- [ ] Title на каждой странице (55-60 символов, с ключевым словом)
- [ ] Meta Description (150-160 символов, привлекательное описание)
- [ ] Meta Keywords (хотя Google их не использует, но для Яндекса)
- [ ] OpenGraph теги (для социальных сетей)
- [ ] Twitter Card теги

### Структура контента
- [ ] Один H1 на каждой странице
- [ ] Иерархия заголовков (H2 → H3 → H4)
- [ ] Минимум 150-200 слов уникального контента на странице товара
- [ ] Внутренние ссылки на связанные товары
- [ ] Хлебные крошки (Breadcrumbs)

### Изображения
- [ ] Alt-текст ко всем изображениям
- [ ] Оптимизированный размер файлов (< 100KB)
- [ ] Форматы WebP/AVIF с fallback
- [ ] Lazy loading для изображений ниже fold
- [ ] Атрибуты width/height указаны

### Доверие и конверсия
- [ ] Актуальные контактные данные
- [ ] Информация о гарантии и возвратах
- [ ] Условия доставки и оплаты
- [ ] SSL сертификат (https)
- [ ] Наличие отзывов и рейтингов

## 3. АНАЛИТИКА И ОТСЛЕЖИВАНИЕ

- [ ] Google Search Console подключен
- [ ] Яндекс.Вебмастер подключен
- [ ] Яндекс.Метрика подключена
- [ ] Google Analytics 4 подключен
- [ ] Цели (goals) настроены
- [ ] События отслеживаются (добавление в корзину, заказ)
- [ ] UTM параметры используются для кампаний

## 4. КОНТЕНТ И ССЫЛКИ

### Контент
- [ ] Блог создан и регулярно обновляется
- [ ] Информационные статьи под целевые запросы
- [ ] Минимум 1000 слов в статьях
- [ ] Внутренняя перелинковка (5-10 ссылок на статью)
- [ ] Внешние ссылки на авторитетные источники

### Ссылочный профиль
- [ ] Ссылки с профильных IT-портал
- [ ] Ссылки из справочников и каталогов
- [ ] Естественное соотношение анкоров (30% коммерческие, 70% информационные)
- [ ] Нет токсичных ссылок (проверено Ahrefs/Semrush)
- [ ] Качество > количество

### Локальный поиск
- [ ] Профиль в Яндекс.Бизнес
- [ ] Профиль в 2ГИС
- [ ] Google Business Profile
- [ ] Актуальные часы работы и адрес
- [ ] Регулярный ответ на отзывы

## 5. МОНИТОРИНГ И ОТЧЕТНОСТЬ

### Ежемесячный мониторинг
- [ ] Позиции по ключевым запросам
- [ ] Органический трафик
- [ ] Количество конверсий
- [ ] Скорость загрузки страниц
- [ ] Core Web Vitals

### Отчеты
- [ ] Скриншоты позиций в начале и конце месяца
- [ ] Таблица сравнения "было/стало"
- [ ] Анализ причин изменений
- [ ] Рекомендации по улучшению

### Инструменты для проверки
- [ ] Google PageSpeed Insights
- [ ] GTmetrix
- [ ] Screaming Frog (анализ структуры)
- [ ] Ahrefs/Semrush (анализ конкурентов)
- [ ] MozBar (анализ авторитета)

## 6. ДОЛГОСРОЧНОЕ РАЗВИТИЕ

- [ ] Анализ поведения пользователей (Heatmaps)
- [ ] A/B тестирование улучшений
- [ ] Расширение семантического ядра (500+ запросов)
- [ ] Создание кластеров похожих товаров
- [ ] Интеграция системы отзывов
- [ ] Реализация динамических фильтров
- [ ] Настройка рекомендаций товаров (AI)
