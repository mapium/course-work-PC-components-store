# Регрессии ответов на отзывы

- `php tests/review-controller.php` — 8 проверок создания и редактирования ответов, родительского отзыва, рейтинга, авторизации и CSRF. Требуется расширение `pdo_sqlite`; база создаётся только в памяти, каждый сценарий откатывается.
- `node --test tests/review-form.test.cjs` — 4 браузерных сценария отправки и редактирования ответов, повторной работы после обновления списка и восстановления обязательного рейтинга для обычных отзывов. Нужны Node.js 18+, Playwright и Chrome.

Браузерные тесты читают страницу товара работающего магазина, подставляют тестовые кнопки в отдельном контексте и перехватывают **все** запросы к API отзывов. Тестовые комментарии не записываются в рабочую БД. Сохранение проверяется отдельно тестом контроллера в SQLite.

Настройки окружения для браузерных тестов:

- `REVIEW_BASE_URL` — адрес магазина; по умолчанию `http://localhost/course-work-PC-components-store`.
- `REVIEW_PRODUCT_ID` — ID существующего товара; по умолчанию `4`.
- `REVIEW_PLAYWRIGHT_PATH` — абсолютный путь к пакету `playwright`, если он установлен вне проекта.
- `REVIEW_CHROME_PATH` — путь к Chrome/Chromium; без настройки используется канал `chrome`.

При ошибке браузерный тест сохраняет скриншот во временную папку и выводит его путь.
