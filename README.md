# 🖥️ PCComponents Store - Интернет-магазин комплектующих для ПК

Полнофункциональное веб-приложение для онлайн продажи комплектующих для персональных компьютеров с встроенной SEO-оптимизацией.

**⚡ [Быстрый старт за 5 минут](./QUICKSTART.md)** | **📖 [Полная документация](./INSTALLATION.md)** | **📋 [Пояснительная записка](./ПОЯСНИТЕЛЬНАЯ_ЗАПИСКА.md)**

## 📋 Требования

| Компонент | Версия |
|-----------|--------|
| PHP | 8.1+ |
| MySQL | 5.6+ |
| Apache | 2.4+ (с mod_rewrite) |
| Браузер | Chrome, Firefox, Safari, Edge |

## Установка

### 1. Клонирование репозитория
```bash
git clone <repo-url>
cd course-work-PC-components-store
```

### 2. Создание базы данных
```bash
mysql -u root -p < database/schema.sql
```

### 3. Конфигурация
Отредактируйте `src/config/Config.php` и `src/config/Database.php` с вашими данными подключения:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'pc_components');
define('DB_USER', 'root');
define('DB_PASS', '');
```

### 4. Настройка веб-сервера
Убедитесь, что корневая папка веб-сервера указывает на папку `public/`.

## Функционал

### Для гостей
- Просмотр каталога товаров
- Поиск и фильтрация товаров
- Просмотр деталей товара
- Регистрация и авторизация
- Добавление товаров в корзину

### Для авторизованных клиентов
- Управление личным кабинетом
- Оформление заказов
- Просмотр истории заказов
- Сохранение адресов доставки

### Для менеджеров
- Управление каталогом товаров
- Управление заказами
- Поиск информации о клиентах
- Формирование отчетов по продажам

### Для администраторов
- Полный доступ ко всему функционалу
- Управление пользователями
- Просмотр аналитики
- Управление конфигурацией системы

## Безопасность

- Пароли хешируются с использованием bcrypt
- Защита от CSRF атак через токены
- Валидация всех входных данных
- Использование подготовленных запросов (PDO)
- HTTPS обязателен для production

## API Endpoints

### Товары
- `GET /api/products` - Список товаров
- `GET /api/products/:id` - Информация о товаре
- `POST /api/products` - Добавить товар (только админ)

### Корзина
- `GET /api/cart` - Содержимое корзины
- `POST /api/cart/add` - Добавить товар в корзину
- `DELETE /api/cart/:id` - Удалить товар из корзины

### Заказы
- `GET /api/orders` - Список заказов
- `POST /api/orders` - Создать заказ
- `GET /api/orders/:id` - Информация о заказе

### Пользователи
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `POST /api/auth/logout` - Выход
