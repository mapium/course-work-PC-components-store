# План выполнения курсовой работы
## Веб-приложение и SEO-оптимизация для интернет-магазина «PC-Components Store»

---

## 1. Общая информация о проекте

**Название системы:** Веб-приложение для онлайн продажи комплектующих для ПК «PCComponents Store»

**Цели проекта:**
- Разработка полнофункционального интернет-магазина комплектующих для ПК
- Автоматизация процессов поиска, выбора, заказа и управления товарами
- Оптимизация веб-приложения для повышения видимости в поисковых системах
- Увеличение органического трафика и количества заказов

**Целевая аудитория:**
- Физические лица (геймеры, энтузиасты, рядовые пользователи)
- Корпоративные клиенты и организации
- Пользователи, ищущие информацию о характеристиках и ценах

**Стек технологий:**
- Backend: PHP 8.1
- Frontend: HTML5, CSS3, JavaScript
- Database: MySQL 5.6+
- Web Server: Apache 2.4+
