# Система управления товарами

## Функционал

### 1. Просмотр товаров
- URL: `/admin?tab=products`
- Отображает таблицу всех товаров с информацией:
  - ID, название, цена, остаток, бренд, статус
  - Цветовая индикация остатков (зеленый >10, желтый 1-10, красный 0)

### 2. Добавление товара
- Кнопка: "Добавить товар"
- URL: `/admin?tab=products&action=add`
- Поля:
  - Название* (обязательное)
  - Категория* (выбор из списка)
  - Цена* (обязательное)
  - Старая цена (для скидок)
  - Остаток (количество на складе)
  - Бренд
  - SKU (артикул)
  - Описание
  - SEO: Meta Title
  - SEO: Meta Description
  - SEO: Meta Keywords

### 3. Редактирование товара
- Кнопка: "Редактировать" в строке товара
- URL: `/admin?tab=products&action=edit&id={ID}`
- Все поля доступны для изменения (кроме ID и slug)
- Кнопки: "Сохранить" / "Отмена"

### 4. Удаление товара
- Кнопка: "Удалить" в строке товара
- Подтверждение через JavaScript confirm()
- Удаляет:
  - Сам товар из таблицы products
  - Все связанные изображения из product_images
  - Все характеристики из product_specifications

## Безопасность

- CSRF защита на всех формах через токены
- Валидация всех входных данных
- Подготовленные запросы (prepared statements) для защиты от SQL injection
- Экранирование HTML при выводе (htmlspecialchars)

## Технические детали

### Обработка форм
Все формы отправляются методом POST на `/admin?tab=products`:
- `action=create` - создание товара
- `action=update` - обновление товара
- `action=delete` - удаление товара

### Автоматическая генерация slug
При создании товара slug генерируется автоматически из названия:
- Все символы в нижний регистр
- Пробелы и спецсимволы заменяются на дефис
- Пример: "Intel Core i7-13700K" → "intel-core-i7-13700k"

### Категории
Список категорий загружается динамически из базы данных при отображении формы добавления.
