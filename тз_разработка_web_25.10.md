ВИД АВТОМАТИЗИРУЕМОЙ ДЕЯТЕЛЬНОСТИ 

1. Наименование системы 

Веб-приложение для онлайн продажи комплектующих для ПК «PCComponents Store» (далее — Система). 

2. Назначение и цели создания системы, целевая аудитория 

Назначение системы: автоматизация процессов поиска, выбора, заказа и онлайн-продажи комплектующих для персональных компьютеров, а также управление каталогом товаров, учет клиентской базы, заказов и складских остатков. 

Цели создания системы: 

Расширение рынка сбыта комплектующих для ПК за счет предоставления круглосуточного доступа к интернет-магазину. Повышение эффективности работы сотрудников отдела продаж, администраторов и руководства. Оптимизация процесса обработки заказов покупателей и контроля складских запасов. Формирование аналитической и финансовой отчетности по продажам за определенные периоды (месяц, год). 

Целевая аудитория: 

- Физические лица (геймеры, энтузиасты, рядовые пользователи), ищущие комплектующие для ПК на заказ (процессоры, видеокарты, материнские платы, накопители и др.); 

- Корпоративные клиенты и организации, заказывающие оптовые партии комплектующих для сборки рабочих станций; 

- Пользователи, ищущие информацию о характеристиках товара, ценах, условиях гарантии и доставки. 

   3. Требования к системе 

Требования к серверному ПО: 

- Операционная система: Linux / Windows Server; 

- СУБД: MySQL для хранения данных о товарах, пользователях, заказах и категориях; 

- Среда разработки: PHP, JavaScript. 

   4. Состав и содержание работ по созданию системы 

Разработка Системы включает в себя следующие этапы: 

- 1) Предпроектный этап: анализ предметной области, анализ конкурентов, выявление требований к функционалу интернет-магазина комплектующих для ПК. 

- 2) Проектирование: разработка архитектуры базы данных, проектирование интерфейсов пользователя (прототипы страниц), описание сценариев взаимодействия ролей. 

Программная реализация (разработка): 

- 1) Создание серверной части: реализация бизнес-логики, обработка запросов, интеграция с СУБД. 

- 2) Создание клиентской части: верстка страниц каталога, корзины, личных кабинетов, адаптивный дизайн. 

- 3) Тестирование и отладка: проверка корректности работы функционала сайта. 

- 4) Подготовка отчетной документации: оформление пояснительной записки к курсовой работе. 

   5. Структура системы и права пользователей 

Типы пользователей и их возможности: 

Гость (неавторизованный пользователь) имеет возможность: 

- Просматривать главную страницу, рекламные баннера и акции, 

- Просматривать каталоги с комплектующими с возможностью фильтрации и поиска по названию или характеристикам, 

- Просматривать детальную информацию о товаре, 

- Регистрироваться в системе и авторизовываться, 

- Добавлять товары в корзину (временную). 

Авторизованный пользователь (Клиент / Покупатель) имеет 

возможность: 

- Весь функционал Гостя. 

- Управлять личным кабинетом (редактирование личных данных, контактной информации, адреса доставки), 

- Оформлять заказы на основе товаров из корзины, 

- Просматривать истории собственных заказов и статусов их выполнения. 

Менеджер / Руководитель отдела продаж имеет возможность: 

- Работать с каталогом товаров (добавление новых комплектующих, редактирование цен, характеристик и остатков на складе), 

- Управлять заказами клиентов (просмотр списка заказов, изменение статусов: «В обработке», «Собран», «Доставляется», «Выполнен», «Отменен»), 

- Выполнять поиск информации о клиентах (поиск по фамилии/телефону), 

- Формировать и просматривать отчеты по продажам за месяц, за год. Администратор / Руководитель предприятия: 

- Полный доступ ко всему функционалу системы. 

- Управление учетными записями пользователей и сотрудников (добавление, редактирование, блокировка/удаление), назначение ролей и привязка сотрудников к отделам. 

- Просмотр аналитических отчетов по продажам, популярности комплектующих, финансовым показателям (в форматах Word/Excel). 

Описание основных форм и страниц: 

Главная страница: содержит шапку сайта (логотип, строка поиска, ссылки на каталог, корзину, личный кабинет), блок промо-баннеров, разделы с популярными и акционными комплектующими, подвал сайта с контактами. 

Страница каталога и карточки товара: сеточный вывод товаров с фильтрами по ценовому диапазону, бренду и характеристикам; страница конкретного товара с описанием и кнопкой «В корзину». 

Форма авторизации и регистрации: поля для ввода логина, пароля, а при регистрации — ФИО, телефона и адреса. 

Личный кабинет клиента: вкладки с персональными данными, текущими и прошлыми заказами. 

Панель управления (Администратора / Менеджера): табличное представление товаров/заказов/сотрудников с панелями фильтрации, кнопками добавления/редактирования и блоком генерации отчетов в Word/Excel. 

# 6. Требования к дизайну 

Цветовая гамма: современный корпоративный стиль в стиле hi-tech. Рекомендуется светлый фон (белый, светло-серый), акценты выполнены в технологичных цветах (изумрудно-зеленый, темно-серый, графитовый с яркими элементами интерактивных кнопок зеленого цвета). 

Заголовки и шрифты: использование читаемых шрифтов без засечек. Иерархия заголовков должна четко структурировать контент. 

Интерактивные требования: 

- Плавная анимация при наведении на элементы интерфейса (карточки товаров, кнопки). 

- Всплывающие уведомления (тосты) при добавлении товара в корзину или успешном оформлении заказа. 

- Валидация полей форм (регистрация, оформление заказа) в реальном времени с подсветкой ошибок. 

- Требования к верстке: адаптивный дизайн с поддержкой мобильных устройств, планшетов и персональных компьютеров 

   7. Требования к информационному обеспечению 

Требования к хранению данных 

Все данные системы должны храниться в структурированном виде, база данных должна быть в третьей нормальной форме. 

Требования к языкам разработки 

Для создания статических страниц необходимо воспользоваться HTML 5 и CSS 3. Для создания динамических страниц, необходимо воспользоваться языком PHP. 

Требования к программному обеспечению 

Для функционирования системы необходимо следующее программное обеспечение: 

- Веб-сервер — Apache версии не ниже 2_4; 

- СУБД — MySQL версии не ниже 5.6; 

- PHP — версия 8.1. 

Требования к пользовательскому программному обеспечению — информационная система должна обеспечивать корректное отображение данных в следующих веб-браузерах: 

- Internet Explorer 9.0; 

- Mozilla Firefox 4.5; 

- Opera 9.5; 

- Safari 3.2.1; 

- Google Chrome 2.
